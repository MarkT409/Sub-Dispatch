How end users opt in to SMS

Path 1 — Website form with unchecked checkbox (primary)

Crew members visit Settings after login and enter a phone number. An unchecked-by-default checkbox must be checked before save.

Live settings page (login required): https://crew-dispatch.com/crew/settings. The checkbox mock above is the public verification of that consent UI.

Path 2 — Verbal / in-person roster enrollment

When a supervisor collects a number in person, they read this script and only save the number if the worker agrees:

“Would you like to receive text messages from Lantana Electric LLC / Crew Dispatch for account sign-in links and job assignment alerts? Message frequency varies. Message and data rates may apply. You can reply STOP at any time to opt out, or HELP for help. Consent is not a condition of employment. Privacy: https://crew-dispatch.com/privacy-policy.html. Terms: https://crew-dispatch.com/terms-and-conditions.html.”
